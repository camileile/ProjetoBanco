# ProjetoBanco

Sistema bancário simples em Java, desenvolvido no NetBeans.

## Conceitos utilizados

- **Classe abstrata:** `Conta`
- **Herança:** `ContaCorrente` e `ContaPoupanca` estendem `Conta`
- **Interface:** `Tributavel`
- **Exceptions personalizadas:** `SaldoInsuficienteException` e `ValorInvalidoException`
- **Tratamento de erros:** `try/catch` com leitura de dados via `Scanner`

## Como executar

Abra o projeto no NetBeans e execute a classe `ProjetoBanco`.
